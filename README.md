# HybridElectro — твой live bd

Банк громкости управляет восемью дорожками внутри жёлтой рамки Launchpad,
TRACK — восемью макросами выбранной дорожки. Выбирать дорожку можно мышью,
AKAI или Launchpad. Количество дорожек не ограничено восемью.

## Громкости следуют рамке

Первый измеренный банк SMC-PAD, канал 1, CC30–37: ручки 1–8 управляют
громкостями дорожек слева направо внутри рамки Launchpad. Горизонтальное
перемещение рамки меняет их назначения, даже без выбора другой дорожки.
Вертикальное перемещение рамки на назначения громкости не влияет.
Учитывается реальный список видимых дорожек контроллера, включая группы.
Для пустых позиций у конца списка ручки отключены. При недоступной или
неоднозначной поверхности Launchpad старые привязки снимаются.

Настройка: `volume_follow_session: {"surface": "Launchpad", "max_db": 0}`.
Она использует банк `encoders.global` вместо фиксированных целей `global`.
Для старых конфигураций без этого поля фиксированный GLOBAL по-прежнему поддерживается.
Не назначай CC30–37 через Cmd+M: постоянные назначения перекроют следование рамке.
Диапазон ручек громкости — от −∞ до **0 dB**: при CC127 достигается ровно
0 dB. Ограничение действует при вращении этих ручек, другие способы управления
фейдерами Live сохраняются. При перепривязке значения не меняются; работает Pickup.
Громкость записывается только при получении движения ручки после захвата текущего
значения. Новая дорожка определяется непосредственно перед обработкой MIDI.

## Как самому назначать TRACK

Второй банк SMC-PAD, канал 1, CC 38–45, всегда управляет Macro 1–8
Rack с именем **PERFORM** на выбранной дорожке.

1. Выбери нужную дорожку.
2. Добавь свои эффекты. Выдели их заголовки и нажми **Cmd+G** — получится Audio Effect Rack.
3. Переименуй Rack в **PERFORM** и открой его макросы.
4. Нажми **Map** в Rack, выбери параметр эффекта, затем кнопку **Map** под нужным макросом.
5. Настрой диапазон Min/Max, если нужен, и выйди из Map.
6. Выбери другой трек — ручки будут управлять его PERFORM.

Каждая дорожка получает собственный набор эффектов и назначений. Можно добавлять новые
дорожки, переименовывать их и макросы: редактировать JSON для этого не требуется.
На дорожке без PERFORM банк TRACK ничего не меняет. При двух Rack с таким именем
на одной дорожке скрипт отключает спорные назначения и пишет причину в журнал.

В рабочей копии на BREAKS уже создан пример: **PERFORM → Utility**.
Macro 1 управляет Stereo Width. Ширина возвращена к нейтральным 100%; остальные
семь макросов свободны. Можешь использовать этот Rack, добавлять в него эффекты
и менять назначения под свой сет.

Используется **Macro Map** внутри Rack. Обычный Cmd+M на тех же CC создаст фиксированные
назначения, которые будут мешать переключению по дорожкам.
Физическую ручку **не нужно** назначать через Cmd+M даже на сами макросы: скрипт
уже связывает её с макросом выбранной дорожки. Если одна ручка одновременно меняет
параметры двух дорожек, проверь и удали её ручные Cmd+M-привязки в режиме TRACK.
Затем на каждой дорожке используй Map внутри своего PERFORM: параметр эффекта →
кнопка Map под Macro 1. Одинаковый номер макроса на разных дорожках здесь допустим.
Управляемые эффекты должны находиться внутри PERFORM. Для громкости/панорамы
внутри Rack можно добавить Utility. Один макрос может управлять несколькими параметрами.

## Что происходит со значениями

Значения остаются у конкретных макросов и эффектов в Ableton. Скрипт при выборе дорожки
меняет связи ручек с параметрами и **не записывает в параметры никаких значений**.
Никакие пресеты или Macro Variations при переключении не загружаются.

Например, на дорожке A макрос остался на 30, на B — на 100. Возвращение на A оставляет 30.
Чтобы эти состояния сохранились и после закрытия проекта, сохраняй Set через **Cmd+S**.
Автоматизация, клиповые огибающие и другие контроллеры продолжают действовать обычным образом.

Энкодеры твоего SMC-PAD отправляют абсолютные значения. В **Settings → Tempo & MIDI →
Takeover Mode** должен стоять **Pickup**; он уже включён при настройке этой версии.
После смены дорожки ручку иногда нужно довести до текущего значения макроса — затем
она начинает им управлять. Это защищает от скачка при первом движении.

## AKAI и Launchpad

Пэды AKAI теперь следуют восьми дорожкам внутри рамки **Launchpad**.
Сместил рамку вправо — назначения пэдов сместились вместе с ней.
Соответствие в порядке измеренных пэдов:

| Note, канал 1 | Позиция дорожки внутри рамки |
| --- | --- |
| 64 | 1 — крайняя слева |
| 65 | 2 |
| 66 | 3 |
| 67 | 4 |
| 60 | 5 |
| 61 | 6 |
| 62 | 7 |
| 63 | 8 — крайняя справа |

Это порядок из замера, а не утверждение о печатной нумерации пэдов на корпусе.
Положение считывается при нажатии пэда из SessionComponent, рисующего рамку:
учитывается реальный список дорожек Launchpad, включая свёрнутые группы.
Вертикальное перемещение рамки не меняет выбор дорожек. Пэд над пустым местом
в конце списка ничего не выбирает. Если Launchpad отсутствует или найдено несколько
одноимённых Control Surface, выбор отменяется с сообщением вместо выбора другой дорожки.
Банк TRACK ручек по-прежнему следует **выбранной дорожке**: сдвиг рамки сам по себе
не выбирает трек и не переключает назначения ручек, это делает последующее нажатие пэда.

Настройка: `pad_follow_session: {"surface": "Launchpad"}` и `track_slot: 1..8` в pads.
Изменение начинает действовать после перезапуска Live; появится запись
`HybridElectroPads ready / follows Launchpad`. Для старого выбора по именам нужно
убрать pad_follow_session и указать track вместо track_slot у каждого пэда.

В Settings нужны:

| Control Surface | Input | Output |
| --- | --- | --- |
| HybridElectro | SINCO (SMC-PAD-Master) | None |
| HybridElectroPads | MPKmini2 | None |
| Launchpad | твой вход Launchpad | твой выход Launchpad |

Пэды AKAI выбирают дорожки, не вызывая Play/Stop/Arm/Record.
Если клавиатура AKAI передаёт те же ноты на том же канале, её клавиши тоже будут выбирать
дорожки: для независимой игры назначь пэдам отдельный MIDI-канал в редакторе AKAI,
затем обнови channel в pads. Если пэды выбора не нужны, отключи HybridElectroPads.

## Установка и дополнительные настройки

Файл настроек в проекте: `HybridElectro/config.json`.
Установленный файл:
`~/Music/Ableton/User Library/Remote Scripts/HybridElectro/config.json`.
`setup_mode: false` включает управление, `true` — диагностику без назначений.
`dump_parameters: true` выводит имена параметров выбранной дорожки в Log.txt.

Для обновления с резервной копией:

```sh
python3 tools/install.py --replace-config
```

`Install.command` устанавливает/обновляет скрипт, сохраняя существующий установленный
config.json. `--replace-config` переносит актуальные настройки из проекта.
Если User Library перенесена, добавь `--library '/полный/путь/User Library'`.

Для диагностики открой `Show MIDI.command`. Подробные измерения — `CALIBRATION.md`.
Пользовательские прямые назначения по именам параметров по-прежнему можно задавать
в `tracks`: они заменяют автоматические макросы только для указанной дорожки.
