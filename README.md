# HybridElectro — SMC-PAD + AKAI, Ableton Live 12

AKAI выбирает дорожку. Восемь ручек M‑VAVE получают её персональные назначения.
Второй банк ручек управляет фиксированным общим микшером. Audio Effect Rack не нужен.

**Сейчас включена диагностика:** скрипт пишет MIDI-сообщения в журнал и не назначает
ручки на параметры. CC в `config.json` — примеры, а не считанные настройки твоего
SMC-PAD. Сначала проверяем контроллер, затем включаем управление.

## 1. Установка на Mac

1. Закрой Live и открой `Install.command` двойным щелчком.
   Он копирует обе папки скриптов в
   `~/Music/Ableton/User Library/Remote Scripts/`.
   При обновлении создаёт резервную копию, установленный `config.json` сохраняет.
2. Запусти Live. В **Settings → Link, Tempo & MIDI** добавь две строки:

   | Control Surface | Input | Output |
   | --- | --- | --- |
   | HybridElectro | MIDI-вход SMC-PAD, на котором приходят ручки | None |
   | HybridElectroPads | MIDI-вход AKAI MPK mini | None |

3. На этих же входах не назначай другие Control Surface. У AKAI оставь **Track On**,
   чтобы клавиши и неназначенные пэды могли играть инструменты.
   У SMC-PAD **Track** нужен, если хочешь играть его пэдами.
   **Remote** нужен для дополнительных обычных MIDI-назначений; сообщения наших
   ручек и пэдов вручную через Cmd+M не назначай. **Sync** для скрипта не нужен.

SMC-PAD может показывать несколько MIDI-портов. Выбираем тот, на котором реально
видны CC ручек в диагностике; имя порта само по себе этого не доказывает.
Для этой версии ручки должны отправлять обычные MIDI CC, а пэды выбора — Note.
Если включён другой протокол, настройки меняются через MidiSuite; прошивку менять не нужно.

Если User Library перенесена, скопируй папки `HybridElectro` и `HybridElectroPads`
в её `Remote Scripts` вручную либо используй:

```sh
python3 tools/install.py --library '/полный/путь/User Library'
```

Python нужен только установщику и просмотрщику журнала. Сам скрипт запускается
на встроенном Python Ableton. Можно установить вручную и открыть `Log.txt` текстовым редактором.

## 2. Узнаём MIDI-команды — без знания CC

Открой `Show MIDI.command`, затем по очереди:

1. В первом банке SMC-PAD покрути ручку 1 медленно вправо, затем влево.
2. Покрути по порядку ручки 2–8.
3. Переключи банк энкодеров и повтори.
4. На AKAI выбери Pad Bank B и нажми пэды для выбора дорожек.

Пример строки:

```text
HybridElectro MIDI CC channel=1 cc=16 value=1
HybridElectroPads MIDI NOTE channel=10 note=40 value=100 on
```

Пришли эти строки и укажи, какие значения получались вправо и влево.
Пустой журнал: проверь подключение, выбранный Input и режим контроллера.
Программа просмотра начинает с **новых** сообщений, поэтому вращай ручки после её открытия.

Журнал твоей установленной версии:
`~/Library/Preferences/Ableton/Live 12.4.15/Log.txt`.
Просмотрщик сам находит недавно изменённый журнал. Сводка уже записанных сообщений:

```sh
python3 tools/midi_log.py --summary
```

Форматы `encoders.track.mode` и `encoders.global.mode`:

| mode | Медленно вправо / влево |
| --- | --- |
| `relative_two_complement` | 1 / 127 |
| `relative_signed_bit` | 1 / 65 |
| `relative_binary_offset` | 65 / 63 |
| `absolute` | Значение постепенно растёт / уменьшается в диапазоне 0–127 |

Это ориентиры для определения формата, а не утверждение о заводском пресете SMC-PAD.
Бесконечная ручка тоже может отправлять абсолютные значения.

## 3. Назначения

Редактируется **установленный** файл:
`~/Music/Ableton/User Library/Remote Scripts/HybridElectro/config.json`.
В нём общий конфиг для обоих скриптов. После изменений перезапусти Live.
JSON не допускает комментарии и лишнюю запятую после последнего элемента.

- `channel` — от 1 до 16, как в редакторе контроллера.
- `cc` — восемь номеров по порядку физических ручек, от 0 до 127.
- Два банка должны различаться CC или каналом. Если сообщения совпадают,
  скрипт не может определить аппаратный банк; измени их в MidiSuite.
- `encoders.global: null` отключает глобальный банк, если он пока не нужен.
- `pads` — реальные канал, номер MIDI-ноты и имя дорожки для пэдов AKAI.
  MIDI-номер используется вместо неоднозначных обозначений C1/C2.
- В `tracks` ключ — точное имя дорожки, список — назначения ручек 1–8.
  `null` вместо назначения оставляет ручку свободной.

Примеры одного назначения:

```json
{"mixer": "volume"}
```

```json
{"device": "Auto Filter", "parameter": "Frequency"}
```

```json
{"send": 1}
```

`send: 1` — первый Send, `send: 2` — второй. Название эффекта на Return не проверяется:
это не обязательно Delay/Reverb. Для микшера доступны `volume`, `panning`,
у Master — `crossfader`. В глобальном списке каждому назначению нужен `track`:

```json
{"track": "DECK A", "mixer": "volume"}
```

Специальные имена: `@master`, `@return:1`, `@return:2` и т. д.
Обычные имена дорожек и устройств сравниваются точно, с учётом регистра.
Устройства ищутся и внутри Rack. Если имена устройств повторяются на одной дорожке,
переименуй нужное в уникальное имя и укажи его в конфиге.

Начальные назначения:

| Ручка | DECK A | BREAKS |
| --- | --- | --- |
| 1 | Volume | Beat Repeat: Grid |
| 2 | EQ Three: Low | Beat Repeat: Variation |
| 3 | EQ Three: Mid | Auto Filter: Frequency |
| 4 | EQ Three: High | Auto Filter: Resonance |
| 5 | Auto Filter: Frequency | Saturator: Drive |
| 6 | Auto Filter: Resonance | Volume |
| 7 | Send 1 | Send 1 |
| 8 | Send 2 | Send 2 |

Это заготовка из диалога. Скрипт сам не создаёт дорожки или эффекты.
Имена параметров зависят от устройства и его версии: с `dump_parameters: true`
выбери дорожку в Live — в журнал попадут имена её устройств и параметров.
В `parameter` подходит `name` или `original_name` из журнала.
Если чего-то нет или имя неоднозначно, соответствующая ручка отключается,
а причина выводится в журнал; другой эффект наугад не выбирается.

## 4. Включаем управление

После проверки MIDI и назначений поставь `setup_mode: false`,
для обычной работы также `dump_parameters: false`. Перезапусти Live.

Банк TRACK всегда относится к выбранной дорожке — пэдом AKAI или мышью.
На дорожке без записи в `tracks` этот банк ничего не управляет.
Банк GLOBAL сохраняет свои назначения независимо от выбора дорожки.
Аппаратный банк определяется по поступающим CC/каналу; отдельное сообщение
от кнопки переключения банка не требуется.

Пэды выбора обрабатываются отдельной маленькой Control Surface, потому что
у AKAI и M-VAVE разные MIDI-входы. Неназначенные пэды AKAI остаются свободными.
Если выбор дорожек у тебя уже настроен, `HybridElectroPads` можно не включать.

Относительные энкодеры управляют параметром штатным MIDI-мэппингом Live.
Для абсолютных включён подхват текущего значения. Само переключение дорожки
не записывает значения параметров; скрипт не вызывает Play, Stop, Arm или Record.
Изменение/переименование устройств подхватывается примерно в течение секунды.
Изменение самого JSON требует перезапуска Live.

## Проверки и ограничения

```sh
python3 -m unittest discover -s tests -v
```

Автоматические проверки работают без Live. Они проверяют выбор целей,
обработку ошибок и взаимодействие со смоделированным API.
Реальный MIDI-ввод, подхват и поведение на SMC-PAD нужно проверить в Live.

Установка пользовательских Python Remote Scripts:
[официальная инструкция Ableton](https://help.ableton.com/hc/en-us/articles/209072009-Installing-third-party-remote-scripts).
Редактор SMC-PAD:
[загрузки M-VAVE](https://www.cuvave.com/download).
